CRUD de Estudiantes con JPA

Descripción

Este proyecto es una aplicación básica de CRUD (Crear, Leer, Actualizar, Eliminar) para gestionar estudiantes utilizando JPA (Java Persistence API). Permite realizar operaciones básicas en una base de datos relacional mediante una capa de persistencia en Java.

Tecnologías utilizadas

Java 8+

JPA (Java Persistence API)

Hibernate (Implementación de JPA)

MySQL / PostgreSQL (Base de datos relacional)

Maven (Gestión de dependencias)
